Generated analysis output lands here and is not version controlled.

Each study writes a .json (machine-readable) and a .txt (the printed report) named after
the study. They are derived from participant recordings, so they are regenerated rather
than tracked -- run the study script to recreate them.

  python Analysis/model_performance_study.py --json Analysis/results/model_performance.json

This README and .gitkeep are the only tracked files in this directory.
