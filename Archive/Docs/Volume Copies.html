Volume Copies
Teacher model · training data augmentation

Volume copies

Volume makes a copy of a training window that is quieter or louder than the original, so the model learns that a weak face can still show an emotion. It is the first step of volume + jitter, and the same rule as model C. All windows on this page are real training windows.

Part 1 · How one volume copy is made

Four steps

step 1Measure the face Face size = the sum of the 63 face action units, averaged over the 5 frames.
step 2Find the allowed range From 0.8 ÷ size to 5.5 ÷ size, kept inside ×1/3 … ×3. Neutral always uses ×0.5 … ×1.5.
step 3Draw one number Random in that range, so that halving and doubling are equally likely (log-uniform).
step 4Multiply the whole window All 350 values get the same number. The face gets quieter or louder and keeps its shape.

Part 2 · The bigger picture
All 6,656 expressive training windows

What volume does to the face sizes of the training data

How to read: each bar counts training windows with that face size. Grey = the real windows, orange = one volume copy of each. The green band is the target, 0.8 to 5.5. Neutral windows are not shown.

The training data is stronger than headset faces (headset sessions have median face sizes of 1.3 to 2.8). Volume moves the copies into the band: very strong faces are made quieter, very weak ones louder. So two out of three copies are quieter.

Inside volume + jitter

Where the volume step sits

  1. Volume number, computed from the original window's face size (steps 1–3 above).
  2. Whole window × volume number.
  3. Jitter: every one of the 350 values × its own number from 0.8 to 1.2.
  4. Clip: every value kept in 0 … 1 (about 0.07% of values are cut).
  5. Neutral check: if the largest value of a Neutral copy is above 0.25, the copy is scaled down to 0.25.
DetailWhat it means
Order of volume and jitterBoth are multiplications and the clip comes once at the end, so jitter first would give the same copy.
Volume only, or volume + jitterThe volume step is identical. Volume alone simply skips step 3.
Difference from model CModel C applied the Neutral 0.25 limit to the volume number itself. Here it is applied to the finished copy, because jitter can push a Neutral value above 0.25 again. Without jitter the two give the same result.
New copies every epochEvery epoch draws new numbers, so the model never sees the same copy twice. 8,181 real windows + 8,181 copies = 16,362 per epoch.
size = X[..., :63].sum(-1).mean(-1)                         # step 1
low  = np.clip(0.8 / size, 1/3, 3)                          # step 2
high = np.clip(5.5 / size, 1/3, 3)
low[neutral], high[neutral] = 0.5, 1.5
g = np.exp(rng.uniform(np.log(low), np.log(high)))          # step 3
copy = X * g[:, None, None]                                 # step 4
copy *= rng.uniform(0.8, 1.2, size=X.shape)                 # jitter (volume + jitter only)
copy = np.clip(copy, 0, 1)                                  # clip
# Neutral check: scale a Neutral copy down if its largest value is above 0.25
